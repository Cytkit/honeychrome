## Works with your cytometer's files

Honeychrome reads FCS files from spectral and conventional instruments, including:

- Cytek Aurora and Northern Lights
- Sony ID7000
- BD FACSDiscover A8 and S8
- BD FACSymphony A5SE
- Beckman Coulter CytoFLEX mosaic
- Thermo Fisher Attune Xenith
- Thermo Fisher Bigfoot
- NovoCyte Opteon
- CytoStellar
- Cytkit
- Conventional cytometers
{: .instrument-list}

***

## Extend it with Python

Honeychrome is written in Python. Plugins add their own tabs with full access to the experiment, the unmixed data and the gates. To use plugins, run Honeychrome as a Python package rather than the downloaded app.

[Programming and plugins](/docs/developers/plugins/){: .more}
